OpenA2A builds the trust layer for AI agents. Agents now act on people's behalf, calling APIs, querying data, and executing tasks, without the identity, authorization, audit, and trust primitives traditional infrastructure has had for decades. OpenA2A fills that gap with open, self-hostable tools and open standards, vendor-neutral by design, so no single platform owns the layer that verifies its own agents.

Built by and for the developers, security teams, and researchers working on AI agents. Apache 2.0 across the ecosystem. This work also feeds the wider agent ecosystem: security disclosures to the agent runtimes, and open standards contributions in flight with Agent2Agent and OpenTelemetry.
